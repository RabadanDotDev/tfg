## Description

This is the repository for the bachelor thesis of Raul Rabadan Arroyo, completed with honors at UPC and available at [UPCommons](https://upcommons.upc.edu/handle/2117/413264) in Spanish. The thesis includes the development of PacketPincer, a network analysis tool, its application to network traces, and the utilization of the results in Machine Learning algorithms. 

## Repository structure

- `packet_pincer`: Contains the main implementation of the PacketPincer tool, written in Rust.
- `report`: Contains the full bachelor thesis report in Spanish, written in LaTeX.
- `paper`: Contains the summarized version of the report with an article format, written in Latex
- `scripts`: Contains auxiliary scripts used during the project for preprocessing, extracting and plotting information and the tool execution, written in a combination of Python and Bash.
